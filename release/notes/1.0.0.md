# 拾遗坊 / RescueAuth 1.0.0

这是拾遗坊原生 Android 应用的首个版本。账户验证码、恢复码和开发者凭据统一保存在本地加密保险库中，通过系统生物识别或设备凭据解锁。

## 主要功能

- 认证器：支持 TOTP、二维码、otpauth 链接及 Google Authenticator 迁移导入，提供倒计时、复制、搜索和账户置顶。
- 恢复码：支持分组管理、已用状态、单条及批量复制、编辑和移动。
- 开发者保险库：管理 API 凭据、SSH 密钥、Android 签名密钥、环境变量组和通用秘密字段。
- 手动迁移与备份：导出独立 PIN 加密的 `.rakpkg` 包，支持选择性导出和合并导入。
- 高敏感操作再次验证，普通删除可撤销；提供中文、英文及浅色、深色主题。

## 从旧版迁移

原生应用使用独立安装标识，可以与旧版 RescueAuthKit 并存。旧版发布到 `1.2.0`，原生版从 `1.0.0` 重新开始编号；仓库文档中的“v2”表示原生重写代际。

在旧版导出 `.rakvault` 后，通过原生版的旧版导入入口输入原密码并预览、合并数据。确认账户和开发者条目迁移完整后，再处理旧版安装。原生版的新备份格式为 `.rakpkg`，旧 `.rakvault` 仅用于兼容导入。

新应用仅提供手动导出，不包含旧版的自动备份或云同步。每份导出包使用独立 PIN，请保留可恢复的数据包。

## 平台

Android 8.0（API 26）及以上。MCP 和桌面 Bridge 不包含在本次版本中。

# RescueAuth 1.0.0

The first native Android release brings authenticator accounts, recovery codes and developer credentials into a local encrypted vault, unlocked with system biometrics or device credentials.

- TOTP with QR, otpauth and Google Authenticator migration import; countdown, copy, search and account pinning.
- Recovery-code groups, used-state tracking, editing, moving and individual or bulk copying.
- API credentials, SSH keys, Android signing keys, environment-variable sets and generic secrets.
- Manual `.rakpkg` export with a separate PIN per package, selective transfer and merge-first import.
- Fresh authentication for sensitive actions, undo for ordinary deletion, Chinese/English and light/dark themes.

The native app installs alongside legacy RescueAuthKit. Its version sequence starts at 1.0.0; “v2” in project documentation means the native rewrite generation. Import legacy `.rakvault` files using their original password and verify the migrated data before removing the old app. Native exports use `.rakpkg`; automatic backup and cloud sync are not included.

Requires Android 8.0 or later. MCP and the desktop Bridge are outside this release.
